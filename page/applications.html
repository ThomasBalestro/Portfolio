APP_005
🐍 Logiciel — Python (CLI)
● Terminé · open source

Coffre

Gestionnaire de mots de passe en ligne de commande. Le coffre est un fichier unique chiffré : sans le mot de passe maître, il est illisible et toute modification est détectée.

  • Chiffrement AES-256-GCM, clé dérivée du mot de passe maître par scrypt
  • Générateur de mots de passe et de phrases de passe (aléa cryptographique)
  • Écriture atomique : le coffre n'est jamais corrompu en cas de coupure
  • 29 tests automatisés : mauvais mot de passe, fichier altéré, cas limites
Python 3 cryptography argparse pytest
